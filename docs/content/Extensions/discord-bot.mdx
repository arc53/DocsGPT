# Discord Bot Integration Guide

This guide will walk you through creating a Discord Bot token and linking it to your DocsGPT instance so you can interact with your documents directly from Discord.

## Step 1: Create a Discord Application
1. Go to the [Discord Developer Portal](https://discord.com/developers/applications) and log in with your Discord account.
2. Click the **New Application** button in the top right corner.
3. Give your application a name (e.g., `DocsGPT Bot`) and agree to the terms, then click **Create**.

## Step 2: Generate a Bot Token
1. In the left-hand menu of your application dashboard, click on the **Bot** tab.
2. Click the **Add Bot** button and confirm the popup.
3. Under the **Token** section, click **Reset Token**. Copy this token immediately and save it securely. *Note: You will not be able to see this token again without resetting it.*

## Step 3: Enable Privileged Gateway Intents
To allow DocsGPT to read and respond to chat messages properly, you must enable the correct gateway privileges:
1. Scroll down on the **Bot** page to the **Privileged Gateway Intents** section.
2. Toggle **ON** the following intents:
   - **Presence Intent**
   - **Server Members Intent**
   - **Message Content Intent** (Crucial for reading user queries)
3. Click **Save Changes**.

## Step 4: Configure DocsGPT Environment Variables
To connect the bot to your DocsGPT backend, you need to add your token to your deployment configuration.

### Using Docker Compose
Open your `.env` file or environment variables settings and add your token:
```env
DISCORD_BOT_TOKEN=your_copied_discord_bot_token_here
```

Restart your Docker containers to apply the configuration:
```bash
docker compose down && docker compose up -d
```

## Step 5: Invite the Bot to Your Server
1. Navigate back to the Discord Developer Portal and select the **OAuth2** tab from the left menu, then click **URL Generator**.
2. Under **Scopes**, select the `bot` checkbox.
3. Under **Bot Permissions**, select the following text permissions:
   - `Send Messages`
   - `Read Message History/View Channels`
4. Copy the generated URL at the bottom of the page, paste it into your browser, select your Discord server, and click **Authorize**.

Your DocsGPT Discord bot is now active and ready to respond to your queries!
